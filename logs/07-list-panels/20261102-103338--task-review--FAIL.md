## Blocking

1. **Switching rows with a panel open** (tasks 2.3, 2.4, 3.3). Opening row B while A's panel is
   open pushes a second entry (list → A → B), so closing B with `back()` reopens A. A's unmount
   also clears the marker B's opener just set, so B's close falls back to replace and leaves a
   dead entry. *Accepted fix:* when a panel is already open, opening another row uses `replace`
   and carries the marker to the new URL; the unmount clear only removes a marker that still
   points at that panel's own URL; unit tests for both, and an AC-17 e2e step (open A, then B,
   Cancel → list without `?item`, one Back leaves the list). Recorded as a task-level refinement
   of fix 2 (no AC meaning change), not a spec revision.

## Non-blocking

1. **AC 8 refusal e2e via a "crafted call"** (task 6.6) would depend on Next's internal Server
   Action protocol. *Accepted fix:* pick a valid docket in the panel, move that docket to another
   client through the DB helper, then Save; assert the toast, the panel stays open, and the order
   is unchanged. The server refusal stays covered by integration (task 6.5).
