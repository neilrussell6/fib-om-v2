## Findings

1. **Severity: low** — `components/resource/panel/panel-shell.tsx:106`. Focus return picks the
   first `[data-item-link="<id>"]` in the DOM. Cache Components keeps recently visited routes
   mounted but hidden, so with the same id on a hidden list (e.g. order 7 on a visited /orders,
   then client 7's panel on /clients) focus goes to the hidden link and drops to the body.
   *Accepted fix:* focus the first visible match; e2e step with a client and an order sharing an
   id.
2. **Severity: low** — `lib/order-items/panel-actions.ts:84`. After fix 1, a direct call that
   sends only one of `order_due_date` / `order_status` returns success and writes nothing to
   the order. *Accepted fix:* exactly one present is a field error ("Required") on the missing
   one, nothing written; integration test.
