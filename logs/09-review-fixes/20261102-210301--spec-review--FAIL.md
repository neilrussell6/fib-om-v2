## Verdict

undefined and partly unreachable, and the coverage script would have run a project that refuses
local databases.

## Blocking

1. **Coverage thresholds contradict OQ3 and may be unreachable.**
   - AC-15 fixes thresholds while OQ3 calls them proposals.
   - `lib/auth.ts` (NextAuth wiring, 0%) and the Neon-only branch of `lib/db/index.ts` (61%)
     can't be covered locally.
   - "The seven helper modules" isn't a list of paths.
   - **Fix:**
     - Exclude `lib/auth.ts` and `lib/db/index.ts` from the `lib/**` threshold. They are still
       reported.
     - Name the helper files by path.
     - Fallback: if a measured figure is below its threshold, lower that threshold to the
       figure rounded down to 5 and log it in the implementation changelog.
     - Replace OQ3.
2. **`npm run test:coverage` would run the new `neon` project.**
   - **Resolved by the author:** drop the Neon smoke test entirely (section, AC-17, OQ4). The
     Neon branch stays out of the threshold (Blocking 1), and the staging deploy remains the
     real Neon check.
