## Findings

1. **Medium: AC-19 is not met as first written** (`logs/09-review-fixes/20261103-220655--tests--PASS.md`).
   - `npm run test:integration` took 45.7 s by vitest's Duration, or 30.2 s as the per-file sum,
     against ≤ 25 s.
   - The time that's left goes on the `seed-dummy` throwaway database, bcrypt at cost 12, the two
     CLI-spawn tests the spec keeps, and the new B2/P1/parity tests. None of it can come from
     moving tests down the pyramid.
   - **Resolved at PR validation:** the target was relaxed to ≤ 50 s, which 45.7 s meets.
2. **Low: a cached label can go stale** (`components/resource/reference-combobox.tsx:60-65`).
   - The label the server passes in is tied to whatever value the combobox holds when the label
     changes.
   - Scenario: two clients have the same name, and a filter switches from one to the other
     through a server render. The label text doesn't change, so it stays tied to the old id and
     the combobox fetches the label again.
   - The result is one extra request; the label shown is still right. Not fixed.
3. **Low: the Auth.js callbacks lose type checking** (`lib/auth.ts:22-23`).
   - Both callbacks are cast `as never`, so if the Auth.js callback signature changes, typecheck
     won't catch it.
   - Unit tests cover `lib/auth/callbacks.ts` itself but not how it's wired into Auth.js.
     Not fixed.
4. **Low: a script imports a test helper** (`scripts/bench-lists.ts:11`).
   - It takes `createThrowawayDb` from `tests/helpers/throwaway-db`.
   - That's fine while the script only runs locally, but moving or refactoring the test helpers
     will now affect it. Not fixed.
